# Crypto Track 📈

A simple and clean cryptocurrency tracker built with React. Browse popular coins, search by name, and view detailed price information.

## 🔗 Live Demo

[Link to demo](https://crypto-track-livid.vercel.app/)

## ✨ Features

- List of popular cryptocurrencies with current prices
- Search coins by name
- Coin detail pages
- Rank, price, and market data
- Coin icons with fallback for missing images
- Responsive design
- Fast and lightweight (React + Vite)

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **React Router**
- **Recharts** (for charts)
- **Coinpaprika API**

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn
